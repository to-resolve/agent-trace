## 4. 决策点与偏离说明

1. **AgentEvent 的定义位置**：任务卡同时要求「types.ts 与 02 第 3、4、5、7、10 节完全一致」和「events.ts 提供 AgentEvent 类型 + isAgentEvent()」。为使两条要求同时成立，`AgentEvent` 定义放在 `types.ts`（第 7 节归属），`events.ts` 通过 `export type { AgentEvent }` 再导出并提供守卫，全项目仅存在一份定义。若架构负责人希望定义本体移入 `events.ts`，为单行改动，可裁决后调整。
2. **types.ts 的收录范围**：严格按任务卡列举的第 3、4、5、7、10 节，未收录第 6 节 `TraversalResult`（属 `core/graph/query.ts`，T3）、第 8 节 `EventHandlers` / `RunHandle` / `TraceSource`（属 `core/source/types.ts`，T2）、第 9 节 `ScenarioMeta` / `Scenario`（剧本模块，T2）。验收标准中「包含 02 中全部类型」按此口径理解为「指定五节的全部类型，零偏差」。
3. **isAgentEvent 校验深度**：顶层字段逐项校验；嵌套 `Span` / `DataEntity` 全字段结构校验；`DataEntity.payload` 类型为 unknown、值任意，仅校验字段存在（`'payload' in v`）；`attributes` 校验为普通对象。未做值的语义校验（如时间戳正负、trustScore 是否在 0–1 区间），属 T2+ 范畴。
4. **未创建 CSS 入口文件**：输出清单与 `docs/01` 目录结构均未列出 `src/index.css`，故未创建。Tailwind 经 `tailwind.config.js` + `postcss.config.js` 就位，样式入口留待后续需要样式的任务卡引入；因此当前页面为无样式纯文本占位。
5. **未添加测试文件**：理由见自测第 3 项，遵守「宁可少做」。
6. **main.tsx 显式判空**：以「判空 + throw」替代非空断言 `!`，属代码风格选择（禁用 any/强转的延伸），非契约要求。
7. **npm 环境备注**：npm 11 的 allow-scripts 机制提示 `esbuild@0.21.5` 的 postinstall 未自动执行；已用 `npx esbuild --version` 验证二进制可用（输出 `0.21.5`），dev server 与浏览器实测均正常，未做额外干预。
8. **依赖版本**：白名单只约束包名与主版本，具体版本取安装时各主版本线最新：typescript 5.9.3、vite 5.4.21、@vitejs/plugin-react 4.7.0、zustand 5.0.15、tailwindcss 3.4.19 等，`npm ls --depth=0` 确认与白名单一一对应、无多余顶层依赖。
