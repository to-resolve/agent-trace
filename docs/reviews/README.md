## 审查优先级

1. **红线** —— 违反直接打回，不进入后续评审
2. **契约一致性** —— 与 `02` 文档零偏差是硬要求
3. **设计是否走偏** —— 实现方式是否背离了技术亮点目标
4. **实现质量** —— 边界处理、错误处理、性能隐患
5. **代码风格** —— 不阻塞通过，但需记录

> 审查发现契约本身有问题时，**改文档而不是将就代码**。
